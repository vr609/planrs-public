📖 Diagram Guide

Teal border = Active bounding box
Top label = Class name (what object)
Corner markers = Box precision points

📜 Drag These Labels

Class Name The category label — e.g. "Cow", "Rickshaw", "Mango"
Confidence Score How certain the AI is — shown as a percentage like 94%
Bounding Box The rectangle drawn around a detected object (x, y, width, height)
Pixel Grid The image broken into tiny squares — each pixel holds colour data

💡 Key Facts

Confidence above 80% = reliable detection
A 1080p image has over 2 million pixels!
Bounding boxes use (x, y, w, h) coordinates
